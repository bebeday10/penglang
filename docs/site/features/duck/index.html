Duck¶

The Penguin Rubber Duck Fish Virus Checker is a rubber duck fish virus checker that debugs penguin's problems.
Most penguins were too lazy to do the work themselves.

What does the duck do?¶

The duck debugs your code either by talking to you personally in a 1:1 meeting or talking to many ducks in a meeting like true ones.

Does the duck truly duck duck?

Yes, the duck does in fact duck ducking by duck ducks ducking.

1:1 meeting¶

The duck does a 1:1 meeting by using talk_to_duck. Once it starts, Duck Mcgeesh will talk to you.

Duck talking edition
Talk to Duck, paste some code, enter on a line saying 'SN' to send. (or 'exit')
