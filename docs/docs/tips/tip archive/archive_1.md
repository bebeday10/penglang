??? tip "Tip #3: For the new v0.10.0: Use bananas"
    Bananas are a great way to increase banana healthiness.  
    Penguins can make bananas by importing it.  
    ```python
    import penglang.modules.pengbanana

    thing = PenguinBanana()
    ```
    They then can use these bananas to eat.  
    ***Don't eat rotten bananas!***
    !!! info "Only works on 0.10.0 and above!"
        This feature only works on 0.10.0 and above.  
        Beware the penguins of 0.9.0 and below.

??? tip "Tip #2: Awesome tip for Windows users"
    If you press and hold the undo/redo button on your mouse on the Start button and release it outside of the Start button, it will be stuck in its hover state until you interact with it again.

??? tip "Tip #1: Dancing"
    Has your penguin ever felt like... dancing?
    Use `dance`, which is in the main PengLang module.  
    Penguins can dance whatever style they want.  
    They can scream too.
    !!! note
        Dancing is in magenta!
