**PengLang** is a [domain-specific language](https://en.wikipedia.org/wiki/Domain-specific_language) that let's penguins code in ***Style***™.

[bebeday10](https://github.com/bebeday10) began working on PengLang on May 31st 2026. 

PengLang has gained extensive use in the **fish** community. It is widely taught to penguins<sup>[1](#fn1)</sup>. PengLang has consistently ranked top penguin on the [Penguin Community Index](<Penguin Community Index>).

# History

PengLang was conceived on May 31st 2026 with the idea of "What if Python was penguins?"<sup>[2](#fn2)</sup>.

# Code examples
```PengLang
say("hello world")
```
# Modules
[Modules](Module) are additions to PengLang that add extra [commands](Command) to PengLang.  
[Fish](Fish) have praised this for "innovation without wasting space for the original".
