# `say_in_a_box`

For some odd reason, penguins wanted to talk in a box.  
Now they would be able to.  
But for what reason?  
To not be heard because secret?  
But why?

Saying in a box is when you fancy your boxes.
```python title="box_luxury" linenums="1" hl_lines="3 4 5 6 7"
import penglang as pl

pl.say_in_a_box(
    message="i live in a box", # (1)!
    title="banana", # (2)!
    box_color="green", # (3)!
)
```

1. It lives in a box. Like metaphorically.
2. Fun fact: the box's name is "banana".
